
Some Ai agents prototypes I built for my own personal use cases using open source Python libraries like LllamaIndex:  

1. Confluence Knowledge Base - query and ask about Confluence wiki content.  
2. PDF documents - query and ask about a PDF document's content including generating a summary.
3. Research buddy (inspired by a featured Llama index tutorial) -  research any topic and generate a final report with the references/sources used from the internet. Also saves report in a PDF file for offline access.
